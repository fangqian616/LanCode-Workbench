CAPABILITIES

为什么选择 AGY Web Workbench

不再让合用主机上的多个用户相互踩工作区、手动传 zip 或猜 CLI 执行进度。

TAKT-STYLE 3-COLUMN WORKBENCH

三栏工作台与 ACP WebSocket 实时流

灵感源自 TAKT 桌面工作台：左侧多会话持久化切换，中间实时展示 Thought 思考过程、工具调用状态卡与流式 Markdown 输出；portal.mjs 在服务端自动将 WebSocket params.cwd 改写至当前用户的独立沙箱目录。

WS /agent -> auto-inject params.cwd = users/<user>/workspace
SSE + DRAG & DROP

文件夹拖拽上传与 SSE 文件树

基于 webkitGetAsEntry() 递归读取本地文件夹，一键保留相对路径上传；右侧工作区通过 /api/events 实时推送变更，60 秒内修改文件带绿色脉冲高亮，底部直接预览图片、SVG 与代码。

SYNCTHING 2-WAY SYNC

室友 / 队员本地文件夹双向同步

集成便携版 Syncthing（GUI 默认绑定 127.0.0.1:8384），为每位成员生成私有共享文件夹 agy-<name>，通过设备 ID 一键配对后，本地 IDE 修改与 Agent 生成产物实时双向同步。

SANDBOX & NTFS ACL

多用户 Token 门户与 Windows ACL 隔离

每名用户拥有独立随机 Token 与 Cookie 会话；portal.mjs 严格校验路径边界，可选配 setup-isolation.ps1 自动创建低权限 Windows 本地账户并配置 NTFS 权限，隔离底层系统目录。

/activity TELEMETRY

主机活动监控与远程运维视图

内置 /activity HTML 仪表盘与 /activity.json 接口，实时查看在线用户、活跃 ACP 会话与文件访问轨迹，方便管理员排查阻塞或审计使用情况。

ZERO EXTERNAL DEPS

纯 Node.js 标准库与一键批处理，5 分钟完成上线

核心 portal.mjs、public/workbench.js 与 tools/agy-launch.mjs 零第三方 npm 运行时依赖，不触发漫长的 node_modules 构建。附带 Install / Start / Manage-Users / Manage-Syncthing / Allow-Firewall / Setup-Isolation 全套双语脚手架。

Install.cmd | Start-Server.cmd | Manage-Users.cmd | Manage-Syncthing.cmd | Allow-Firewall.cmd
ARCHITECTURE

请求流向与安全隔离边界

客户端无需暴露底层 CLI 端口或本机磁盘，所有文件操作与 ACP 会话均经过 Portal 身份校验与沙箱重写。

LAYER 01 · CLIENT

团队成员浏览器 / 本地 IDE

  • 通过专属链接 /login?token=... 登录工作台
  • 三栏界面发起 ACP 对话，拖拽上传文件或文件夹
  • 可选通过 Syncthing 同步本地 IDE 目录
->
LAYER 02 · PORTAL (:3088)

portal.mjs 安全网关与静态服务

  • 校验 users.json Token 与 HttpOnly Cookie
  • 拦截路径穿越，限制文件 API 于 users/<name>
  • WS /agent 代理并自动覆盖 params.cwd
->
LAYER 03 · HOST & SYNC

Antigravity ACP (:3090) & 存储

  • tools/agy-launch.mjs 拉起或诊断 Antigravity CLI
  • SSE /api/events 实时监听并广播文件树变动
  • Syncthing (:8384 / :22000) 与可选 NTFS ACL 隔离
OPERATIONS

开箱即用的命令行与批处理工具箱

所有操作均有对应的 PowerShell 脚本（.ps1）与双击可用入口（.cmd），覆盖安装、用户管理、双向同步与权限隔离。

                使用维度

                所有人共用同一目录，极易误删或覆盖彼此代码

                手动配置反向代理、鉴权服务和同步脚本
